# Meray Hair Salon - React & Tailwind Landing Page

This is a modern React conversion of the Z-ONE landing page website, maintaining 100% of the original visual UI, layout, typography, animations, color palette, and interactive product variants.

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (for vector icons)

## Features & Component Structure
- `src/components/Preloader.jsx`: Initial loading screen with percentage loader and entry animation.
- `src/components/Header.jsx`: Navigation bar with brand logo, nav links, and interactive cart/account actions.
- `src/components/ColorSelector.jsx`: Interactive color picker switching between shoe models and background colors (Blue, Red, Purple, Yellow).
- `src/components/Hero.jsx`: Main stage showcase featuring giant typography, animated shoe transitions, dynamic background colors, and order actions.
- `src/components/RevealOnScroll.jsx`: Intersection Observer scroll-trigger animations.
- `src/components/TechSpecs.jsx`: 3-column feature specs breakdown with Lucide icons.
- `src/components/Story.jsx`: Rotating marquee banner, brand narrative, and 3D preview card.
- `src/components/LabBlueprint.jsx`: Blueprint grid with phase cards (Sketch, Material, Fit, Smart Weave) and prototype view.
- `src/components/CultureBanner.jsx`: Interactive expanding 3-column banner (Urban, Sport, Culture).
- `src/components/Testimonial.jsx`: Verified athlete review with star ratings and avatar.
- `src/components/Footer.jsx`: Newsletter subscription, footer links, socials, and large outline branding.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
